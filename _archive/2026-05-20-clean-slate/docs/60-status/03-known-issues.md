## Issue lifecycle

- **Open:** identified, not yet resolved.
- **In-progress:** being actively worked.
- **Mitigated:** workaround in place; not yet root-cause-fixed.
- **Resolved:** root cause fixed; verified by gate.
- **Won't-fix:** decided not to address (with rationale).

## How to file an issue

1. Add a row to the Open issues table with the next sequential ID (e.g., `H-001`).
2. Severity: Critical (substrate corruption / data loss), High (functional regression), Medium (performance / quality), Low (cosmetic).
3. Workaround: how to operate around it until resolved.
4. Tracking: link to PR/branch/conversation context.
5. Add detailed analysis to a separate file `60-status/issues/H-NNN-summary.md` if the issue requires more than a row of context.
